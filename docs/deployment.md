# Deployment Guide

Deployment documentation now lives in [`docs/deployment/`](./deployment/).

Start with [`docs/deployment/README.md`](./deployment/README.md).

For the agreed admin deployment and first-provisioning procedure, use the
[Admin Deployment runbook](./deployment/admin.md). It records required
infrastructure changes and verification gates, not confirmation of a live rollout.

The latest deploy configuration is tracked separately from the docs:

- [`deployment/stack.yml`](../deployment/stack.yml)
- [`deployment/nginx/7spade.conf`](../deployment/nginx/7spade.conf)
